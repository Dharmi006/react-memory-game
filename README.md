# Memory Card Game 

A fun React memory card game built using React and Vite.

## Features

- Pokemon cards fetched from API
- Score tracking
- Best score tracking
- Card shuffle after every click
- Responsive design

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Pokemon API

## Installation

npm install
npm run dev
